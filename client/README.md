# Chronis

AI-Powered Behavioral Intelligence Platform

## Overview

Chronis is a behavioral intelligence platform that transforms behavioral signals into explainable insights, confidence scores, timelines, and reports.

The platform focuses on transparency, allowing users to understand not only what changed but also why a conclusion was reached.

---

## Features

### Dashboard

* Behavioral Score
* Confidence Gauge
* AI Analysis Panel
* Activity Feed
* Productivity Trend Chart
* Radar Metrics

### Insight Explorer

* Supporting Evidence
* Confidence Indicators

* Long-Term Trend Tracking
